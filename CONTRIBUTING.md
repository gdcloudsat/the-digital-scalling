# Contributing to The Digital Scaling

We welcome contributions to improve this CMS! Please follow these guidelines.

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** to your local machine.
3. **Create a new branch** for your feature or bugfix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Implement your changes** following the project's coding standards.
5. **Run tests** (if applicable) to ensure no regressions.
6. **Commit your changes** with clear, descriptive messages.
7. **Push to your branch**:
   ```bash
   git push origin feature/your-feature-name
   ```
8. **Open a Pull Request** against the `main` branch.

## Coding Standards
- Follow PSR-12 for PHP.
- Use meaningful variable and method names.
- Keep controllers thin and models focused.
- Ensure all new features are documented.
- Use Tailwind CSS for all frontend styling.

## Reporting Bugs
If you find a bug, please open an issue on GitHub with:
- A clear description of the bug.
- Steps to reproduce.
- Expected vs. actual behavior.
- Screenshots if applicable.
