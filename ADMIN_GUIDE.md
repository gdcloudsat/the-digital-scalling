# Admin Guide

Welcome to The Digital Scaling Admin Panel. This guide will help you manage your agency's content.

## Getting Started

- **URL:** `yourdomain.com/admin`
- **Default Login:** `admin@example.com` / `password`

## Content Management

### 1. Services
- Create and edit the services your agency offers.
- Use FontAwesome classes (e.g., `fas fa-code`) for icons.
- Set the `Order` to control how they appear on the homepage.

### 2. Projects (Portfolio)
- Showcase your best work.
- Upload a featured image and multiple gallery images.
- Link to live websites using the URL field.

### 3. Blog (Insights)
- Share your expertise and company news.
- Use the rich text editor for formatted articles.
- Set a publication date to schedule posts.

### 4. Careers
- Manage job openings.
- Toggle `Is Active` to show or hide listings.

### 5. Leads
- View all contact form submissions.
- Check "Popup Leads" for quick inquiries.

## Settings
Navigate to the **Settings** section to manage:
- Site Logo & Favicon
- Contact Information (Phone, Email, Address)
- Social Media Links
- SEO Global Meta Tags
- Custom Scripts (Google Analytics, etc.)
