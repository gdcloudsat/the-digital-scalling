# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-05-26
### Added
- Initial release of The Digital Scaling CMS.
- Full Filament admin panel for content management.
- Responsive frontend with Home, About, Services, Projects, Blog, Careers, and FAQ.
- Lead capture system with contact forms and popup leads.
- Spatie Settings integration for global configuration.
- SEO fields for all major content types.
- GSAP and AOS animations.
- WhatsApp integration.
- Dynamic legal pages.
- Comprehensive documentation.
