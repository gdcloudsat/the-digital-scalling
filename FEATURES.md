# Features

The Digital Scaling comes packed with features designed for digital agencies.

## Frontend Features
- **Modern Responsive Design:** Optimized for all devices (Mobile, Tablet, Desktop).
- **Dynamic Services:** Showcase your offerings with custom icons and detailed pages.
- **Project Portfolio:** Categorized project showcase with image galleries.
- **Insights/Blog:** Full-featured blog with categories and related posts.
- **Careers:** Open job listings with application instructions.
- **FAQ:** Interactive accordion-style frequently asked questions.
- **Contact Management:** Contact forms with lead capture and WhatsApp integration.
- **SEO Ready:** Customizable meta titles and descriptions for all entities.
- **Smooth Animations:** GSAP and AOS powered scroll animations.

## Admin Features (Filament CMS)
- **Dashboard:** Overview of leads and recent content.
- **Service Management:** Easy CRUD for services with icon selection.
- **Portfolio Management:** Manage projects, categories, and media.
- **Blog Engine:** WYSIWYG editor for blog posts.
- **Lead Tracking:** Manage inquiries from contact forms and popups.
- **Career Management:** Post and manage job openings.
- **Legal Pages:** Edit Privacy Policy and Terms of Service dynamically.
- **General Settings:** Manage site logo, social links, and contact information via Spatie Settings.

## Technical Features
- **Laravel 11:** The latest and greatest from the PHP ecosystem.
- **Filament v3:** Beautiful and powerful admin panel.
- **Tailwind CSS 4:** Utility-first CSS for rapid styling.
- **Spatie Media Library:** Robust image and file handling.
- **SEO Fields:** Built-in fields for search engine optimization.
